# 📚 Perler Bead Community Resources

A curated, community-maintained collection of tools, color references, and guides for perler bead artists of all levels.

> Maintained by the [perlerbeads.io community](https://perlerbeads.io). All contributions welcome — see [CONTRIBUTING.md](./CONTRIBUTING.md).

- Brand color charts: Hama, Artkal, Perler (Beados), Nabbi

### 🛠️ [Tools & Software](./tools/)

- Pattern design tools and image converters
