# 🛠️ Tools & Software

A curated list of tools useful for perler bead artists. Organized by use case.

---

## Pattern Design

| Tool | Platform | Description | Free? |
|------|----------|-------------|-------|
| [perlerbeads.io](https://perlerbeads.io) | Web | Pattern editor, color suggestions, sharing | ✅ |
| [Piskel](https://www.piskelapp.com) | Web | Pixel art editor, good for drafting patterns | ✅ |
| [Aseprite](https://www.aseprite.org) | Desktop | Professional pixel art editor | 💰 |

## Image to Pattern Converters

| Tool | Platform | Description | Free? |
|------|----------|-------------|-------|
| [perlerbeads.io](https://perlerbeads.io) | Web | Upload image → bead pattern with color matching | ✅ |
| [Img2Go Pixel Art](https://www.img2go.com/pixelate-image) | Web | Quick pixelation tool | ✅ |
