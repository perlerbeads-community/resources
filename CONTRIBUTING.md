# Contributing to perlerbeads Community Resources

Thank you for helping grow this resource library! Here's how to contribute.

## What We Accept

- Color charts, palettes, and brand comparisons
- Links to useful tools (with a short description)
- How-to guides and technique walkthroughs
- Printable templates (grids, worksheets)

## What We Don't Accept

- Spam or self-promotion without genuine community value
- Copyrighted images without permission
- Duplicate entries (search first)
- Off-topic content

## How to Contribute

1. **Fork** this repository
2. **Add your content** in the appropriate folder:
   - Color info → `color-references/`
   - Tools → `tools/README.md` (add a row to the table)
   - Guides → `guides/` (new `.md` file)
3. **Open a Pull Request** with a short description of what you added and why it's useful
4. A maintainer will review and merge, or leave feedback

## Writing Style

- Write in English
- Keep it concise and practical
- Use tables for comparison data
- Link to original sources when referencing external content

## Questions?

Post in [Discussions](https://github.com/orgs/perlerbeads-community/discussions) if you're unsure where something belongs.
