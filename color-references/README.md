# 🎨 Color References

Community-maintained color charts and cross-brand matching guides.

## Brand Color Charts

| Brand | Bead Count | Notes |
|-------|-----------|-------|
| Perler (Beados) | ~80 colors | Most common in North America |
| Hama | ~200 colors | Popular in Europe, more color variety |
| Artkal | ~200+ colors | Two bead sizes (S=2.6mm, C=5mm), vibrant range |
| Nabbi | ~170 colors | Common in Scandinavia |

## Cross-Brand Matching

Color matching between brands is approximate — dye lots vary. Always test with physical beads before committing to a large project.

**Community resources:**
- [Bead Color Matcher](https://www.beadcolormatcher.com) — visual cross-brand matcher
- [Artkal Color Chart PDF](https://www.artkal.com/color-chart) — official Artkal colors

## Contributing a Color Palette

Submit a PR with a new file in this folder following the format:

```
palettes/
  your-palette-name.md
```

Include: palette name, brand, hex codes, a preview image or description, and the use case (e.g., "pastel spring tones", "Ghibli film inspired").
